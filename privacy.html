개인정보처리방침

오늘노트(Today Board) · 최종 수정일 2026년 9월 1일

1. 요약

오늘노트는 서버가 없는 로컬 데스크톱 앱입니다. 사용자의 할 일과 캘린더 데이터는 사용자 본인의 컴퓨터에만 저장되며, 개발자에게 전송되지 않습니다. 개발자는 사용자의 데이터를 열람·수집·저장·판매하지 않습니다.

2. 접근하는 정보와 사용 목적

권한 범위https://www.googleapis.com/auth/calendar
사용 목적 ① 앱이 만든 전용 캘린더(기본 이름 오늘보드 할 일)에 사용자의 할 일을 일정으로 생성·수정·삭제
② 사용자의 다른 캘린더 일정을 읽어서 앱 화면에 표시 (다른 캘린더는 수정하지 않습니다)
계정 정보이메일 주소·프로필 등 추가 개인정보는 요청하지 않습니다.

사용자가 Google 로그인을 하지 않으면 캘린더 관련 기능만 비활성화되며, 나머지 기능은 그대로 사용할 수 있습니다.

3. 데이터 저장 위치

  • 할 일·설정·메모: %APPDATA%\today-board\data.json (사용자 컴퓨터)
  • Google 인증 토큰: %APPDATA%\today-board\credentials.json — Windows DPAPI로 암호화되어 해당 Windows 계정에서만 복호화됩니다.
  • 캘린더 데이터: 사용자의 Google 계정 내

개발자가 운영하는 서버, 데이터베이스, 로그 수집 시스템은 존재하지 않습니다. 분석 도구(애널리틱스)나 광고 SDK도 포함되어 있지 않습니다.

4. 제3자 제공

없습니다. 데이터는 사용자의 컴퓨터와 Google API 사이에서만 직접 오갑니다. 개발자를 포함한 어떤 제3자에게도 전달되지 않습니다.

5. Google API 서비스 사용자 데이터 정책

오늘노트가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책을 준수하며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다.

  • 사용자 데이터는 앱의 기능(할 일과 캘린더 동기화) 제공 목적으로만 사용합니다.
  • 광고 목적으로 사용하거나 제3자에게 이전하지 않습니다.
  • 사람이 사용자 데이터를 읽지 않습니다 (앱은 사용자 컴퓨터에서만 동작합니다).

6. 데이터 삭제 및 권한 철회

  • 앱 안에서: 설정 → 연결 해제 — 저장된 토큰이 삭제되고 Google에 권한 철회가 요청됩니다.
  • Google 계정에서: myaccount.google.com/permissions 에서 앱 접근 권한을 언제든 취소할 수 있습니다.
  • 로컬 데이터: %APPDATA%\today-board 폴더를 삭제하면 모든 기록이 제거됩니다.
  • 앱이 만든 오늘보드 할 일 캘린더는 Google 캘린더에서 직접 삭제할 수 있습니다.
