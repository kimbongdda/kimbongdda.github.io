오늘보드 사용설명서

Windows 10/11 · 오늘 할 일 관리 + 구글 캘린더 양방향 동기화
설치구글 연결할 일 추가 3가지 유형반복화면 5개 태그·테마단축키자주 묻는 질문

1. 설치

1
다운로드 페이지에서 비밀번호를 입력해 TodayBoard-Setup-1.0.0.exe 를 받은 뒤 더블클릭합니다.
2
"Windows의 PC 보호" 파란 창이 뜨면 추가 정보 → 실행을 누르세요. 개발자 인증서를 구입하지 않아서 뜨는 경고이며, 바이러스와는 무관합니다.
3
설치가 끝나면 바탕화면에 오늘보드 아이콘이 생깁니다.
창을 닫아도 앱은 트레이(시계 옆 ^)에 남아 계속 동기화합니다. 완전히 끄려면 트레이 아이콘 우클릭 → 종료. 설정에서 윈도우 시작 시 자동 실행을 켜두면 켤 때마다 알아서 뜹니다.

2. 구글 캘린더 연결

1
우측 상단 ⚙ 설정 → 구글 계정 연결
2
브라우저가 열리면 본인 구글 계정으로 로그인
3
"Google에서 확인하지 않은 앱" 경고가 나오면 고급 → (앱 이름)(으)로 이동 → 권한 허용

연결되면 구글 캘린더에 오늘보드 할 일 캘린더가 자동으로 생깁니다.

앱 → 구글날짜가 있는 할 일이 오늘보드 할 일 캘린더의 일정으로 생성·수정·삭제됩니다.
구글 → 앱그 캘린더에서 일정을 옮기거나 이름을 바꾸면 앱에 반영됩니다. 거기에 직접 만든 일정도 할 일로 들어옵니다.
다른 캘린더읽기 전용입니다. 왼쪽 타임라인에 표시만 되고 앱이 절대 수정하지 않습니다.
스마트폰에서도 보고 싶다면 — 구글 캘린더 앱에서 오늘보드 할 일 캘린더를 켜면 됩니다. 목록에 안 보이면 폰 브라우저로 calendar.google.com/calendar/syncselect 에 접속해 체크하세요.

3. 할 일 추가 — 한 줄이면 끝

맨 위 입력창에 그냥 적고 Enter. 아무 설정도 안 하면 오늘 할 일로 들어갑니다.

날짜·시간·태그를 문장에 섞어 쓰면 알아서 인식합니다.

시간오후 3시 9시 반 14:00 14:00-16:00
소요1시간 30분 2시간 30분 → 종료 시각 자동 계산
태그#연구
프로젝트@논문
중요도! 중요 · !! 매우 중요

외우기 싫으면 입력창 아래 버튼을 쓰세요.

  • 날짜 칩 — 오늘 / 내일 / 모레 / 이번 주말 / 다음 주 월 / 날짜 없음
  • 📅 날짜 — 달력이 열립니다. 기간 모드로 시작~종료를 잡거나, 여러 날짜 모드로 연속이 아닌 날짜를 여러 개 찍을 수 있습니다 (찍은 날마다 할 일이 하나씩 생깁니다).
  • 🔁 반복 — 매일 / 매주 / 격주 + 요일 + 종료일
  • 📝 메모 — 할 일과 함께 저장할 메모 (Ctrl+M)
  • 태그 버튼 — 눌러서 붙이기

4. 할 일의 3가지 유형

📌 하루 일정그날 하는 일. 기본값.
⏳ 마감형"그날까지만 하면 되는 일". 매일 기한 있는 일 칸에 D-3 로 뜨고, 한 번 완료하면 끝입니다. 예: 과제 서류 처리
금요일까지 서류 처리하기 처럼 "까지"를 붙이면 자동으로 이 유형이 됩니다.
🔁 반복수업이나 매일 하는 공부. 날짜마다 항목이 따로 생겨서 그날그날 체크하고 그날의 진행 메모를 따로 남길 수 있습니다.

항목을 클릭해 열면 위쪽에서 유형을 바꿀 수 있습니다.

5. 반복 일정

한 줄로 만들기:

  • 매주 월수금 9시 알고리즘 수업 12/20까지
  • 매일 논문 읽기 #논문
  • 격주 목요일 저널클럽
  • 평일 아침 9시 출근 체크

항목을 열면 아래 두 버튼이 더 보입니다.

저장그날 하나만 바뀝니다. 그 항목은 이후 규칙 변경에서 보호됩니다.
반복 전체에 적용앞으로의 항목 전체에 반영. 이미 완료했거나 개별 수정한 항목은 건드리지 않습니다.
반복 전체 삭제규칙과 앞으로의 항목을 삭제. 완료한 지난 기록은 남습니다.

왼쪽은 오늘 시간표입니다. 구글 캘린더 일정과 시간을 정한 할 일이 표시되고, 시간을 안 정한 할 일과 밀린 일은 위쪽 종일 · 시간 미정 줄에 모입니다.

밀린 일은 사라지지 않고 3일 밀림 배지를 달고 오늘 맨 위로 올라옵니다. 전부 오늘로 / 다음 주로 / 날짜 없음으로 / 전부 완료 버튼으로 한 번에 정리하세요.

7. 태그와 테마

기본 태그 10개 — 연구 · 논문 · 실험 · 과제 · 수업 · 세미나 · 미팅 · 행정 · 사이드 · 개인. 태그 색이 그대로 구글 캘린더 일정 색이 됩니다. 설정 → 태그 색상에서 이름과 색을 바꿀 수 있습니다.

상단 ◐ 버튼으로 테마 16종 중 고를 수 있습니다. 오른쪽 아래 그림은 클릭하면 크게 보이고, 설정 → 아트 패널에서 원하는 이미지로 교체하거나 앱 전체 배경으로 깔 수 있습니다.

9. 자주 묻는 질문

내 할 일을 개발자가 볼 수 있나요?

아니요. 서버가 없습니다. 데이터는 본인 PC(%APPDATA%\today-board)와 본인 구글 계정에만 있습니다. 자세한 건 개인정보처리방침을 보세요.

구글 캘린더의 기존 일정이 지워지진 않나요?

앱은 오늘보드 할 일 캘린더에만 씁니다. 다른 캘린더는 읽기만 합니다.

동기화가 안 될 때

상단 동기화 칩을 눌러 재시도하세요. 계속 실패하면 설정 → 연결 해제 후 다시 연결하면 대부분 해결됩니다.

업데이트는 어떻게 하나요?

새 버전이 나오면 앱 상단에 🎉 새 버전이 나왔습니다 알림이 뜹니다. 지금 업데이트를 누르면 알아서 받고, 다 받으면 지금 재시작으로 적용됩니다. 나중에를 누르면 그냥 넘어갑니다.

매번 묻는 게 번거로우면 설정 → 업데이트 → "새 버전을 자동으로 내려받아 설치" 를 켜세요. 알아서 받아두고 다음에 앱을 껐다 켤 때 적용됩니다.

어느 쪽이든 할 일 데이터는 그대로 유지됩니다.

백업하고 싶어요

탐색기 주소창에 %APPDATA%\today-board 를 붙여넣고 data.json 을 복사해 두세요.

완전히 지우려면

제어판에서 프로그램 제거 → %APPDATA%\today-board 폴더 삭제 → 구글 계정 권한에서 앱 접근 취소.

건의 · 버그 제보

앱 상단바의 💬 버튼을 누르면 개발자에게 바로 메일을 보낼 수 있습니다. 진단 정보(버전·윈도우·테마)를 함께 보낼 수 있고, 할 일 내용은 절대 포함되지 않습니다.

🎨 원하는 테마 있으시면 언제든 요청 주시면 만들어 드립니다. 원하는 이미지도 같이 보내주시면 감사하겠습니다 — 그 이미지의 색을 뽑아 UI 전체 색감을 맞춰 드립니다. 건의 창에서 🎨 테마 요청을 고르고, 메일 앱이 열리면 그림 파일을 첨부하시면 됩니다.
